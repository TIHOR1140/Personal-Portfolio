📌 **About The Project**

This portfolio serves as a professional online presence, showcasing educational background, technical certifications, and project work. The design incorporates a cyberpunk aesthetic with glassmorphism effects and smooth animations to create an engaging user experience.

✨ **Core Features**

Responsive Layout -	Adapts seamlessly across desktop, tablet, and mobile devices

Interactive Project Cards	- Modal popups with detailed project information

Dynamic Navigation -	Active section highlighting during scroll

Contact Form	- Functional form integrated with Web3Forms API

Animated UI Elements	- Floating badges, hover effects, and scroll-triggered animations

Education Timeline -	Visual chronology of academic and certification history



🛠️ **Technical Stack**



Markup -	HTML5

Styling - 	CSS3 (Custom animations, gradients, glassmorphism)

Interactivity -	Vanilla JavaScript

Icons	- Boxicons

Form Processing -	Web3Forms API

📧 **Contact Form Configuration**


The form currently uses Web3Forms API. To use your own endpoint:

    1. Visit Web3Forms
    
    2. Create a free account and obtain an access key
    
    3. Replace the existing key in index.html
